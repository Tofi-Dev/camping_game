# 🌲🏕️🌲 Forest Survival Type Game
This is a simple pico-8 prototype i'm making before i remake this in 3d in godot.

I don't really have a proper title for this game yet, so keep that in mind.



## Features to implement:

Currently Implemented:
- Rendering Engine (needs improvement)

Partially Implemented:
- Player (still needs systems)

General:
- Monsters
- Basic Inventory
- Survival mechanics
    - Health
    - Hunger
- Day/Night cycle

Daytime:
- Collect food
- Craft things 
- Decorate your campsite (optional)

Night:
- Run from horrors
- Go to the campfire
- Wait out the night
- Risk it, for more loot even.

Items:
 - Emergency Shotgun (But increases difficulty after each use)
 - Some basic food items
 - Med kits
 - Sticks, stones, etc.
 - Fire starters and materials to keep the campfire going

Starting items:
 - Single use fire starter kit
 - 1 piece of food
